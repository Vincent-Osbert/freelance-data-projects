# Freelance data projects

Two small, finished projects that show the work I take on as a freelance data analyst: cleaning messy spreadsheets and quality-checking text labels.

| Project | What it shows | Open |
|---|---|---|
| [01 Excel data cleaning](01-excel-data-cleaning/) | Raw public inspection records to an analysis-ready Excel workbook, every change counted, live before/after formulas, tests | `deliverable/Chicago_Food_Inspections_Cleaned.xlsx` |
| [02 Text annotation QA](02-text-annotation-subride/) | Annotation guidelines, blind relabel, Cohen's kappa, error taxonomy, suspect-label flags on an Indonesian dataset | `deliverable/SubRide_Annotation_QA.xlsx` |

Both use public data with their licences stated in each README. Both document what was changed and what I am unsure about.
