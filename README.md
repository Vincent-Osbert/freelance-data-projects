# Freelance data projects

Three small, finished projects that show the work I take on as a freelance data analyst: cleaning messy spreadsheets, building Excel dashboards, and quality-checking text labels.

| Project | What it shows | Open |
|---|---|---|
| [01 Excel data cleaning](01-excel-data-cleaning/) | Raw public inspection records to an analysis-ready Excel workbook, every change counted, live before/after formulas, tests | `deliverable/Chicago_Food_Inspections_Cleaned.xlsx` |
| [02 Text annotation QA](02-text-annotation-subride/) | Annotation guidelines, blind relabel, Cohen's kappa, error taxonomy, suspect-label flags on an Indonesian dataset | `deliverable/SubRide_Annotation_QA.xlsx` |
| [03 Excel sales dashboard](03-excel-sales-dashboard/) | 12 months of real orders in one workbook: PivotTables, slicers, a timeline, PivotCharts, and an XLOOKUP customer lookup | `deliverable/Online_Retail_Sales_Dashboard.xlsx` |

All use public data with their licences stated in each README, and document what was changed and what I am unsure about.
